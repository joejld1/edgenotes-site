Built around one motion

Above fullscreen, across Spaces

The panel joins every Space and floats above other apps' fullscreen windows, so summoning it never yanks you somewhere else. Sandboxed notes apps can't do this — it's why EdgeNotes isn't in the App Store.

Plain markdown, on disk

Headings, emphasis and code style themselves as you type, and a ``` block sets the whole thing in monospace. The file stays plain text with the markers intact — ordinary .md, no database, no export step. Point the folder at iCloud or a git repo and you have sync.

Quiet by design

No Dock icon, no window, no permission prompts on first launch — the hotkey and hot edge avoid Accessibility gates entirely. Every action is reachable from the keyboard.

The honest bits

Your notes stay yours. Every note is a markdown file in a folder you choose. Delete EdgeNotes tomorrow and the notes are still sitting there, readable in any editor. Nothing is uploaded, nothing phones home.

Not in the App Store, on purpose. Floating above fullscreen apps and joining every Space isn't possible inside the sandbox. The app is Developer ID signed and notarized instead, so it opens clean on any Mac.

What it doesn't do. No iOS app, no sync service, no AI, no folders-and-tags system to maintain. It's a scratchpad that shows up fast and gets out of the way — that's the whole product.
